# BCM Filled Body Bag Asset

This asset was supplied for BCM Body Bags as `packaged corpse.fbx` with separate body-bag and corpse PBR texture sets.

## Runtime resources

- `BCM_FilledBodyBag.xob` preserves the original imported source model for reference.
- `BCM_FilledBodyBag_Collision.xob` contains the player-sized `bodybag` visual mesh and its low-complexity `UBX_BCM_FilledBodyBag` collision proxy. This is the runtime model used by the prefab.
- `Data/BCM_BodyBag.emat` drives the `bodybag` material slot.
- `Data/BCM_Corpse.emat` and the corpse texture set are retained as editable source assets but are not used by the runtime bag.
- The runtime material uses Reforger `_BCR` and `_NMO` packed textures.

The packed source textures are generated by `Tools/PackBodyBagTextures.ps1`:

- `_BCR`: albedo RGB and roughness A.
- `_NMO`: normal X R, normal Y G, metallic B, and ambient occlusion A.

The individual Albedo, AO, Height, Metallic, Normal, and Roughness PNG files are retained as editable source maps. Height is not currently consumed by `MatPBRBasic`.

## Collision

The supplied FBX contains `bodybag`, `packed_corpse`, and `packed_corpse2`, but no Enfusion collision mesh. `Tools/GenerateBodyBagCollisionFbx.py` produces the runtime FBX using only `bodybag`, scales it to approximately 2.13 m long by 0.90 m wide by 0.35 m high, and adds a slightly larger `UBX_BCM_FilledBodyBag` collision box. The collision uses the common plastic physical material and is consumed by the prefab's root rigid body.
