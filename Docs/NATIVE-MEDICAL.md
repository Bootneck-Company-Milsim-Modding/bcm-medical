# Native medical integration status

The standalone project now augments SCR_CharacterDamageManagerComponent directly. Native characters receive the BCM patient without replacing the shared Character_Base resource. The adapter currently applies to all native characters, including AI. It uses native hit zones, DOT effects, consciousness and character replication. ACE is absent from the runtime load path.

Aggregate health has a one-point floor until the authoritative death policy permits death. Native zero blood starts the existing configurable grace policy; repeated damage cannot restart it. Passive blood regeneration cannot bypass depleted reserve. A saline tick must deliver a positive measured reserve increase before it can rescue a casualty. Explicit FullHeal resets BCM injuries/depletion along with native health. Destroyed characters are not resurrected by FullHeal.

Physiology uses normalised gameplay oxygen delivery, lung capacity, blood reserve and tension penalties. Low blood or oxygen sustained past the configured onset interval causes nonshockable arrest. CPR provides partial perfusion; a shock only changes an advised rhythm. Reversible causes, oxygenation and a stable interval with CPR are required for circulation recovery. Prolonged poor delivery accumulates terminal injury debt. These rules are an original deterministic game model, not a clinical simulator. Electrical-cause VF generation, airway procedures, respiratory equipment, drugs and treatment UI still need implementation.

Native kinetic/collision damage records wounds by hit-zone region. Native bleeding introduced outside a direct impact also receives a persistent wound record. The native DOT remains the sole writer for external blood loss; BCM sets its rate from active wound records and owns dressing wear. Native bandaging dresses all linked wounds in that group. Unsutured dressings can reopen, restore a native bleeding effect and bleed at the configured reduced recurrence rate. Native tourniquet reduction remains in the native DOT path. Per-impact effective armour damage calibration and blast/burn-specific injury generation remain incomplete.

Internal sources and fracture motion loss write to native blood separately from external DOT. Thoracic sources accumulate in the correct pleural compartment. Destroyed native leg hit zones record persistent fractures. Splints improve the replicated movement cap; fractures block jumping/climbing even with a splint. A splint does not repair the fracture. Native group movement damage is released for supported fractured legs so it cannot negate the splint improvement. Facility-only repair is currently a domain rule; the authenticated kit/facility treatment adapter is not yet implemented. Real locomotion, AI movement and interference with other movement effects need further play testing.

43 generated GM settings are saved using schema 4. Valid schemas 1, 2 and 3 files migrate without losing existing named values. Authority publishes hypoxic/unconscious state rather than asking clients to reinterpret a local default threshold.

Dedicated native acceptance in .checks/20261026-124825-619 passed 184 assertions: native unconsciousness, depletion, measured-fluid policy, full heal, wound recording, real blood loss, native bandage, reopening, jump restriction, splint movement cap and internal/pleural blood loss. This is not evidence that the complete medical mod is playable. The medical menu and authenticated player treatment workflow still need to be built.
