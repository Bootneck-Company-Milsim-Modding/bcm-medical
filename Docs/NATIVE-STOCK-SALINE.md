# Native stock saline continuity

BCM retains the exact original native stock source, its patient binding and remaining simulation time. Patient state resumes an allowed native saline effect only after the original source resolves in the correct native slot under the current clinical model. Physical used-bag lifetime is saved on the item independently of its holder or the patient's clinical state. Retrieving a used bag or applying FullHeal does not grant another lifetime. Unused original bags acquire no used-source timer.

Current implementation adds BCMM_ZStockSalineSourceLife.c and one serializer entry to the existing Item.conf, preserving finite-supply and native inventory entries. Its optional payload is a named object with schema1 and remaining seconds. It avoids inventory-context polymorphic state. Restore retains an earlier existing deadline; callbacks rearm against world time and delete only their exact source. Original callbacks get a completion-frame grace before fallback cleanup. Legacy attached-source patient state can seed a missing independent item timer. Older retrieved sources whose age was never stored cannot have an unknown historical age reconstructed.

The manual protocol is now shared through BCMM_ZStockSalineSourceCodec.c. Known primitive JSON payloads are rejected before native child-field lookup or base mutation; valid, absent, zero-lifetime, schema and bounds cases have native codec checks. Null source lookup cannot match a different deleted item's weak-null handle. Actual native deletion reproduced that bug647/1, then passes647/0 after the guard; the standard genuine used-source movement/deletion case passes672/0. Same-process world teardown and broader malformed containers remain separate validation.

Native treatment rechecks current policy, physical source and deadline. FullHeal stops the old tracked effect. Duplicate binding detection matches source, patient and model, allowing the same original source to resume under a replacement model without resetting its physical lifetime. Source loss/expiry stops delivery. These are native time/rate semantics; no custom finite-mL capacity is claimed for stock bags. Clinical schema1,270 settings/schema33 and the existing GM tab are unchanged.

Persistence format matters. Native .bin contexts have no primitive-key seeking and report every primitive key as present. Optional binary state therefore uses named-object detection. Seekable contexts use key detection and primitive-leaf rejection before class decoding. JSON existence/object entry does not establish object shape; native class lookup on a scalar crashed during isolated probing. The production guard and valid-object/scalar contracts avoid that known path. Broader malformed-container and arbitrary-addon behavior remains separate.
