# Native BCM Medical arsenal integration

The addon overrides the existing inventory catalog resources for US, USSR and FIA, keeping their original resource GUIDs and paths. Standard faction arsenal boxes and other arsenals using those catalogues therefore see BCM medical supplies without replacing placed boxes with special new ones. Weapons, clothing and other ordinary entries are preserved. The native HEAL category is labelled **BCM Medical** through the existing UI configuration.

Each catalogue contains 28 distinct medical inventory prefabs: native field dressing and tourniquet plus the 26 BCM inventory items. Native morphine/saline/medical-kit catalogue entries are replaced by the standalone medical selection. All advanced drugs, oxygen, treatment equipment, fluid types, folded body bag and drag rope belong to the medical category. The deployed stationary stretcher is a world object and is deliberately excluded from pocket-item inventory entries; a folded deployment kit and GM world-placement catalogue remain separate work.

All item prices, three faction availability controls and the refund fraction are saved under the Arsenal heading within the single BCM Medical GM tab. Prices use native supply/military-allocation transactions. Refund defaults to zero. When enabled, refunds for finite fluid bags, oxygen cylinders and AEDs are rounded down from the live item price times the configured refund fraction times the remaining fraction of their original capacity. Existing devices retain their original capacities when GM defaults change. The separate native personal-allocation calculation applies the same policy. Active treatment supplies are rejected before the native refund transaction can credit resources. Existing carried supplies remain usable when availability is disabled. Other mods replacing these same native catalogue resources can conflict through load order; acceptance uses this standalone addon with the base game.

`Tools/ArsenalItems.json` is the inventory manifest. `Tools/Generate-Arsenals.py` rebuilds the overrides from the matching installed-game configuration extract and records native/override hashes in ARSENAL-OVERRIDE-MANIFEST.json. Review regenerated differences after game updates; do not blindly assume a native catalogue copied from an older version remains complete.

Native runtime reflection accepted all three original GUIDs, 28 unique valid inventory items per faction, live price keys, zero default refunds and the actual BCM Medical category label. The retained ordinary-entry counts are 187 US, 166 USSR and 105 FIA. Multiplayer catalogue reflection and actual menu medical procedures are checked separately; catalogue loading alone does not prove every native arsenal purchase/refund interaction or interoperability with every third-party arsenal.

## Finite-supply refund evidence

Native run .checks/20261029-080048-505 passed 598 assertions with zero failures. Actual saline, oxygen and AED items at price 120 and refund fraction 0.5 returned 45, 59 and 57 after depletion. The separate native personal-allocation calculator matched, zero refund remained zero, and changing capacity defaults did not refill existing devices. This proves catalogue/calculator behavior; complete owning-client purchase/refund resource transfer is still under development.

Native public transaction RPCs: .checks/20261029-081611-314 passed 606 assertions / 0 failures. Disabled Medical purchase spent nothing and created nothing; valid saline purchase moved 1000 supplies to 880 and created the bag in actual buyer storage; after 125 mL depletion, refund moved 880 to 925 and removed that exact bag. Repeating the stale item refund did not credit again. This is local native RPC/transaction acceptance; dedicated owning-client replication is being checked separately. The diagnostic container/arsenal prefab is confined to Tests/Runtime.

Dedicated owning-client acceptance: .checks/arsenal-network-20261029-082231-072/result.json reports Passed=true and SourceUnchanged=true, 606 authority assertions / 0 failures. Actual owner sent all four requests. Owner and proxy observed 1000 -> 880 -> 925 and unchanged duplicate-refund balance; the late joiner observed final 925. Observers hold the same native consumer subscription used by the inventory UI. Initial observer trials without that subscription are rejected as whole-gate evidence. This covers the explicit saline transaction path; broader mixed-container, faction, insufficient-budget and contention cases remain.
