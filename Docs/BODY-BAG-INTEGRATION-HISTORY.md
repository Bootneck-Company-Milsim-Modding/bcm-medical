- Standard vehicle inventory works without a blanket Vehicle_Base prefab override. Movable backpacks inside vehicles remain personal containers; fixed authored vehicle storage is eligible. Native capacity and stationary-vehicle limits apply.
- Actual dead characters receive session-scoped authority death tokens. The original token follows the corpse into its filled bag. Disposal records survive physical deletion. Verified player identity/deployment linkage and independent disposition gating are implemented. Native timer, exact-death release and stale-remains tests pass with diagnostic identities; real backend reconnect acceptance remains unfinished.

Stationary-bag, native natural-surface, range, actor and original player connection/control checks continue until commit. The replicated grave receives memorial data before `BURIED` is recorded and the exact bag is disposed.
- Real native open inventory views have independent controller/character-bound search sessions. Active searching excludes burial, home, dragging and cargo insertion. Close, range loss, possession change and disconnect release only matching sessions; stale replies and transport revisions cannot affect a newer search. See [search protocol and native evidence](BODY-BAG-SEARCH.md).
- Return-home checks the native enabled healing station's actual area, including its configured offsets/bounds. It records `SENT_HOME` before disposing the world bag.
